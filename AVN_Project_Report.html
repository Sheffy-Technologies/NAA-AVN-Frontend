Platform Targets: Web (Vite/React), Desktop (Tauri + Electron configs present)

1. Executive Summary

This project is a modular, enterprise-scale operational dashboard for Nigerian Army Aviation. It is built with React 19 + TypeScript and organized by features, supporting role-based access, real-time capabilities, finance workflows, inventory and procurement lifecycles, operations, maintenance tracking, document handling, reporting, messaging, and user/security administration.

2. Technology Stack

  • Frontend framework: React 19 + TypeScript + Vite
  • Routing: React Router with lazy-loaded route modules
  • State/API: Redux Toolkit + RTK Query + Axios base query
  • Styling: Tailwind CSS v4 + design tokens
  • Utilities: html2canvas + jsPDF for PDF export, xlsx for spreadsheet workflows
  • Realtime: Laravel Echo + Pusher
  • Desktop packaging: Tauri 2 and Electron build paths
  • Testing: Vitest + Testing Library

3. Architecture & Organization

  • src/app: app shell, route definitions, guarded layouts, global store wiring
  • src/features: domain modules (auth, finance, inventory, maintenance, operations, etc.)
  • src/shared: cross-cutting hooks, UI atoms, icons, utilities, common API helpers
  • Permission-gated routing: RequireAuth + RequireRole wrappers around protected pages
  • Code splitting: lazy imports for most route-level pages

5. Routing & Access Control Highlights

  • Protected routes across finance, inventory, operations, maintenance, security, reports, and documents.
  • Fine-grained permission arrays used to gate each domain module.
  • Graceful loading states with route-level suspense fallbacks.
